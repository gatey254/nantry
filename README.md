# Nandi Pulse Bot

Cloudflare Workers + D1 + Telegram bot for public trend intelligence around Nandi County.

## Confirmed V1 sources

- Google Trends: official Trending Now supports RSS export. Use the RSS URL generated by Google Trends and place it in `GOOGLE_TRENDS_RSS_URL`.
- Google News: Google News RSS search feeds for Nandi County/Kapsabet.
- YouTube Data API v3: official `search.list` endpoint for Nandi/Kapsabet queries.
- Telegram Bot API: official HTTPS webhook.

## Important limitation

Google Trends gives strong Kenya-level trend signals, but it does not guarantee a clean county-level "Nandi" feed. Therefore the V1 combines Google Trends with Nandi-specific Google News and YouTube signals rather than pretending we have private or perfect county search data.

## Setup

1. `npm install`
2. `npx wrangler login`
3. `npx wrangler d1 create nandi-pulse`
4. Put the returned database id into `wrangler.jsonc`.
5. `npx wrangler d1 execute nandi-pulse --remote --file=schema.sql`
6. `npx wrangler secret put TELEGRAM_BOT_TOKEN`
7. `npx wrangler secret put TELEGRAM_WEBHOOK_SECRET`
8. `npx wrangler secret put GOOGLE_TRENDS_RSS_URL`
9. `npx wrangler secret put YOUTUBE_API_KEY`
10. `npm run deploy`
11. Set the Telegram webhook to `https://YOUR-WORKER.workers.dev/telegram/webhook` and pass the same secret token.

The bot then supports `/start`, `/help`, `/trends`, `/rising`, `/topic ...`, and `/collect`.
